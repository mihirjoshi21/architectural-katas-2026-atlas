# Glossary

| Term | Meaning here |
|---|---|
| Animal / species / group | An animal is an individual; a species is a classification; a group may need population-level records. The brief's animal count is not species count. |
| Ticket / entitlement / redemption | Purchase/issuance grants a right; redemption records using that right. Purchase alone is not physical entry. |
| Occupancy / popularity / queue | Occupancy is people present; popularity is a specified comparative measure; a queue is waiting demand. Their measurement errors differ. |
| Local link / backhaul | Sensor/staff connectivity inside the estate versus a gateway's route to cloud. |
| Accepted event | Event committed to the application's durable outbox, not merely seen by a sensor or broker. |
| Receipt / custody | Final receipt asserts committed destination processing within the defined contract; carrier custody only says a copy was transferred. |
| Advisory estimate / confirmed fact | Model/manual estimate carries uncertainty; authorized reconciliation produces a separate confirmed record. |
| Proposed / executed / field validated | A design choice, an observed software check, and representative real-world evidence are different statuses. |
| C4 container | A logical application/data-store unit, not necessarily a Docker container or deployment node. |
